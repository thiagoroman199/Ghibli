Decisiones de Diseño

Se optó por una estética minimalista, con una paleta inspirada en Studio Ghibli, priorizando suavidad, legibilidad y coherencia visual. El sitio utiliza un enfoque mobile-first para asegurar una correcta experiencia en dispositivos móviles.

API Utilizada

Se consumió la Ghibli API para obtener información de las películas: imágenes, títulos y directores.

Documentación: ghibliapi.vercel.app/films

Detalles Técnicos del Proyecto

  • HTML semántico para mejorar accesibilidad
  • CSS Mobile First con grid responsive
  • JavaScript modularizado
  • Manejo de errores en fetch y estados visuales (loading/error)
  • Validación completa del formulario de contacto
